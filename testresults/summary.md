# LOSO 跨被试情绪识别 — 改进实验总结

## 1. 问题诊断

### 1.1 原始代码的问题

对 `src/` 中所有 LOSO 相关代码的审查发现以下问题：

**（a）早停策略与 LOSO 目标脱节**

早停依据 source domain 的验证准确率（val_acc）选择 best checkpoint，但 LOSO 关心的是 target domain 的泛化能力。训练日志显示两者严重脱钩：

| Fold | Best Val_Acc | Test Acc | Gap |
|------|-------------|----------|-----|
| sub1 | 73.29% | 39.59% | 33.7% |
| sub2 | 95.90% | 76.44% | 19.5% |
| sub3 | 99.26% | 70.86% | 28.4% |
| sub4 | 99.64% | 76.37% | 23.3% |

Val_acc 接近 100% 但 Test acc 只有 70%——早停选出的往往是 source-domain overfitter。
我认为目前验证集划分有些问题，所以后续测试忽略了val acc的表现。原因是我们想跨被试预测，但是验证集的划分并没有跨被试，而是一个被试的数据会混在验证集和训练集中。如果后续保留验证集的功能，最好给验证集单独划分一个被试。

**（b）训练 epoch 数不是瓶颈**

实验验证：强制训练 5 个 epoch 或 50 个 epoch，test acc 无明显变化。说明瓶颈不在早停优化问题上，所以后续测试实验都跑固定的epoch数。

**（c）11 个被试直接合并为一个源域不合理**

域适应算法（MMD/CORAL/DANN）将 11 个被试拼合后当作单一源域，但这 11 个人的 EEG 分布各异，拼合后形成多模态混合分布。MMD 对齐的是这个不真实的"平均分布"，而非有意义的脑电特征结构。

**（d）混合归一化进一步恶化问题**

原始归一化用 11 人混合的均值/标准差做 z-score，归一化后的源域仍是 11 个分散的簇。

---

## 2. 改进思路

### 思路 C：被试级归一化（Per-Subject Normalization）

**核心改动**：在合并之前，先对每个被试用自己的均值/标准量做 z-score，使 12 个人都被拉到同一尺度（均值=0，标准差=1），再合并构建 LOSO fold。

```
原版：11人原始数据 → concat → 用混合统计量 z-score → 源域（分散的簇）
改进：每人用自己的统计量 z-score → concat → 源域（紧凑的分布）
```

- `train2_dann.py`：DANN + 被试级归一化
- `train2_mmd.py`：MMD + 被试级归一化

### 思路 B：加权多源域适应（Weighted Multi-Source Adaptation）

**核心改动**：不合并 11 个源被试，而是各自独立作为源域，逐个与 target 计算 MMD 并加权求和。

```
原版：concat(11人) → 单次 MMD(source混合, target)
改进：Σ w_s × MMD(source_s, target)，w_s ∝ exp(-d_s / τ)
```

权重用 softmax + 温度参数计算：
- τ 小 → 权重集中在最近的源被试（尖锐）
- τ 大 → 权重均匀（平坦）

- `train3_mmd.py`：MMD + 被试级归一化 + 加权多源 + 温度参数

## 4. 关键发现

### 4.1 被试级归一化是最有效的改进

- DANN：64.49% → 73.80%（**+9.3%**），标准差从 13.3% 降到 8.8%
- MMD：66.09% → 75.15%（**+9.1%**），标准差从 13.1% 降到 7.8%

特别值得注意的是 **sub1**（原始 DANN 39.59% → 被试级归一化 72.96%，提升 33 个百分点），说明该被试的原始信号分布与群体均值差异极大，混合归一化完全无法对齐它。

### 4.2 方差显著下降

所有改进方法的标准差都比原始方法更低（8-9% vs 13%），说明改进不仅提升了平均精度，还让模型在不同被试上的表现更稳定。

### 4.3 加权多源的效果与被试级归一化接近

加权多源 MMD（74.56%）与纯被试级归一化 MMD（75.15%）差距不大。原因：被试级归一化后，11 个源被试到 target 的 MMD 距离集中在 0.19–0.26 的窄区间内，即使引入温度参数 softmax，权重区分度仍然有限。可以考虑用调超参的方式进一步优化。

### 4.4 部分被试反而下降

被试级归一化在 sub2、sub3 上略有下降。可能的解释：这些被试的原始分布本来就比较"标准"，混合归一化恰好把它们对齐到了一个有利的位置，被试级归一化反而去除了这个"有利偏差"。

## 6. 后续可尝试的方向

1. **方向 1（动态权重）**：在模型特征空间中（而非原始特征）计算 MMD 距离，每 K 个 epoch 更新权重——模型学到的特征可能比原始特征更有区分力
2. **方向 2（Top-K 选择）**：不使用所有 11 个源被试，只选 MMD 距离最小的 K 个——硬选择可能比软加权更有效
3. **方向 3（早停改进）**：目前验证集划分有些问题，改进验证集划分会更有利
4. **方向 4（加权多源改进）**：目前加权多源还没有带来显著正提升，并且测试也不足，可以考虑优化
5. **方向 5（改进模型本身）**：改进模型本身，比如加注意力机制，而不是单纯mlp
