# 基于域适应的跨被试脑电情绪识别研究

## 摘要

脑电（EEG）情绪识别在跨被试场景下面临严重的域偏移问题：同一模型在不同被试上的泛化性能显著下降。本文基于SEED数据集，系统研究了归一化策略与三种域适应方法——CORAL、MMD、DANN——的协同效果。实验采用留一被试交叉验证（LOSO）协议，主要发现如下：(1) 被试内归一化是单一最有效的改进，使基线准确率从55.20%提升至70.73%（+15.54%）；(2) MMD域适应在被试内归一化下达到最佳76.25%，相比混合归一化基线提升+21.05%；(3) CORAL对超参数λ最鲁棒（极差仅1.07%）；(4) t-SNE可视化证实域适应方法有效对齐了源域与目标域的特征分布。

**关键词**：脑电情绪识别；域适应；跨被试泛化；SEED数据集；留一被体验证

---

## 1 引言

### 1.1 研究背景

情绪识别是人机交互、脑机接口和智能健康等领域的核心问题之一[1]。基于脑电信号（EEG）的情绪识别因其高时间分辨率和直接反映大脑活动的特性，近年来受到广泛关注。然而，EEG信号具有显著的个体差异性：不同被试的脑电信号在均值、方差、频谱分布等方面存在系统性差异，导致在已知被试数据上训练的模型难以直接泛化到新被试。这一现象在迁移学习中被称为"域偏移"（domain shift）。

域适应（Domain Adaptation）是迁移学习的一个重要分支，旨在利用源域的标注数据和目标域的无标注数据，学习域不变的特征表示，从而缩小域间分布差异。常见的域适应方法包括基于统计量的对齐（如CORAL）、基于核方法的分布距离度量（如MMD）以及基于对抗训练的域分类器（如DANN）。

### 1.2 研究目标

本文围绕以下问题展开研究：

1. **归一化策略的影响**：传统的混合归一化（使用全部源域数据统计量进行z-score）与被试内归一化（每个被试独立z-score后再合并）对跨被试迁移的影响有多大？
2. **域适应方法的有效性**：CORAL、MMD、DANN三种方法在LOSO协议下的表现如何？它们与归一化策略的结合效果如何？
3. **超参数敏感性**：域适应损失权重λ对不同方法的影响有多大？
4. **特征可视化的解释**：不同方法学习到的特征空间中，源域与目标域的对齐程度如何？

### 1.3 主要贡献

本文的主要贡献包括：

- 系统比较了归一化策略与三种域适应方法的组合效果，揭示了被试内归一化作为域适应前置步骤的重要性
- 发现MMD方法在被试内归一化下达到最优76.25%的LOSO准确率，相比混合归一化基线提升+21.05%
- 进行了详细的λ敏感性分析，揭示了三种方法的鲁棒性差异
- 通过混淆矩阵和t-SNE可视化从分类结果和特征分布两个角度解释了各方法的效果

## 2 相关工作

### 2.1 脑电情绪识别

郑伟龙和陆宝亮[1]构建了SEED数据集，包含15位被试（实际可用12位）在观看积极、中性、消极三类情绪视频时采集的62通道脑电信号。每个通道被分为5个频段（δ、θ、α、β、γ），因此每个样本的特征维度为310维。该数据集已成为脑电情绪识别领域的标准基准。

### 2.2 域适应方法

**CORAL（Correlation Alignment）**[2]通过最小化源域和目标域特征协方差矩阵之间的Frobenius范数差异来对齐二阶统计量。其损失函数为：

$$L_{CORAL} = \frac{1}{4d^2}\|C_s - C_t\|_F^2$$

其中$C_s$和$C_t$分别为源域和目标域特征的协方差矩阵，$d$为特征维度。

**MMD（Maximum Mean Discrepancy）**[3]通过在再生核希尔伯特空间（RKHS）中度量两个分布之间的距离来实现域对齐。本文采用多核RBF-MMD，使用带宽为{0.5, 1.0, 2.0, 5.0, 10.0}的高斯核之和作为核函数：

$$\text{MMD}^2(X_s, X_t) = \mathbb{E}[k(x_s, x_s')] - 2\mathbb{E}[k(x_s, x_t)] + \mathbb{E}[k(x_t, x_t')]$$

**DANN（Domain-Adversarial Neural Network）**[4]通过梯度反转层（GRL）实现对抗域适应。GRL在前向传播中为恒等映射，在反向传播中将梯度乘以$-\alpha$，使特征提取器朝增大域分类误差的方向优化。域适应强度参数$\alpha$在训练过程中从0线性增长到1：

$$\alpha(p) = \frac{2}{1 + e^{-10p}} - 1, \quad p = \frac{\text{epoch}}{\text{max\_epochs}}$$

### 2.3 跨被试脑电识别中的域适应

已有工作将域适应应用于EEG信号处理。同项目原始代码实现了CORAL和MMD方法，报告LOSO准确率分别为66.06%和67.45%。本文在此基础上，引入了DANN方法，并重点研究了归一化策略与域适应的交互效应。

## 3 方法

### 3.1 数据预处理

#### 3.1.1 数据集

本文使用SEED数据集[1]，包含12位有效被试（编号1–5, 8–14，被试6和7数据缺失）在3次实验中采集的EEG数据。每位被试每次实验观看15个视频片段（5个积极、5个消极、5个中性），每个样本为62通道×5频段=310维特征向量。三分类标签：消极(0)、中性(1)、积极(2)。

#### 3.1.2 特征提取

原始数据为(N, 5, 62)形状的多频段多通道特征矩阵，将其展平为(N, 310)的一维特征向量作为模型输入。

#### 3.1.3 归一化策略

本文比较两种归一化策略：

**混合归一化（Mixed Normalization）**：将所有源域被试数据合并后，使用合并数据的均值和标准差进行z-score归一化，再用同一组统计量归一化目标域数据。这是传统LOSO实验的常规做法。

**被试内归一化（Per-Subject Normalization）**：对每个被试（包括源域和目标域）独立计算均值和标准差，分别进行z-score归一化后再合并。这一策略消除了被试间的均值和尺度差异，使不同被试的特征分布更加对齐。

### 3.2 数据划分

采用留一被试交叉验证（LOSO）协议：每次将1位被试的全部数据（3次实验）作为测试集（目标域），其余11位被试的数据作为训练集（源域）。从源域中分层抽取20%作为验证集用于模型选择。共进行12折交叉验证，报告平均准确率和标准差。

### 3.3 模型架构

所有实验使用统一的MLP骨干网络，结构如下：

| 层 | 输入维度 | 输出维度 | 激活函数 | 正则化 |
|----|---------|---------|---------|--------|
| Linear 1 | 310 | 256 | — | BatchNorm + Dropout(0.3) |
| Linear 2 | 256 | 128 | — | BatchNorm + Dropout(0.3) |
| Linear 3 (分类器) | 128 | 3 | — | — |

对于域适应模型，前两层构成特征提取器，输出128维特征向量；第三层为分类器，输出3维情绪预测。

DANN额外包含域分类器：128 → 64 → 2（源域/目标域），通过梯度反转层与特征提取器对抗训练。

总参数量约114K。

### 3.4 训练策略

#### 3.4.1 基线模型

总损失为交叉熵损失：

$$L = L_{cls}(\hat{y}, y)$$

#### 3.4.2 域适应模型

总损失为分类损失与域适应损失的加权和：

$$L = L_{cls}(\hat{y}, y) + \lambda \cdot L_{DA}$$

其中$\lambda$为域适应损失权重。对于CORAL和MMD，$L_{DA}$为相应损失；对于DANN，$L_{DA}$为域分类器的交叉熵损失。

#### 3.4.3 超参数设置

所有C/D/F组实验使用统一超参数：

| 参数 | 值 |
|------|-----|
| 最大训练轮次 | 20 |
| 学习率 | 5×10⁻⁴ |
| 批大小 | 128 |
| 权重衰减 | 10⁻⁴ |
| 随机种子 | 42 |
| 验证集比例 | 20%（分层抽样） |
| 早停 | 无 |
| 学习率调度 | CosineAnnealing |
| 优化器 | Adam |

λ敏感性实验中，λ取{0.1, 0.5, 1.0, 2.0, 5.0}。

![混合归一化与被试内归一化对比](figures/comparison_bar.png)

**图2：混合归一化与被试内归一化下各方法对比**

**分析**：三种域适应方法均显著优于基线模型。DANN在混合归一化下提升最大（+14.37%），但标准差仍较高（±10.29%），表明其对不同被试的效果不稳定。CORAL和MMD效果相近，MMD略优。混合归一化下所有方法的准确率均不超过70%，暗示归一化策略是限制性能的重要因素。

### 4.2 被试内归一化与域适应方法对比（D组）

表2和图2展示了被试内归一化条件下的实验结果。

**表2：被试内归一化下域适应方法对比（D组，λ=1.0）**

| 方法 | 混合归一化 | 被试内归一化 | 差值 |
|------|-----------|-------------|------|
| MLP baseline | 55.20% | **70.73%** | +15.54% |
| MLP+CORAL | 64.70% | **73.44%** | +8.74% |
| MLP+MMD | 65.46% | **76.25%** | +10.79% |
| MLP+DANN | 69.56% | **74.89%** | +5.33% |

**分析**：

1. **被试内归一化是单一最有效的改进**：仅将归一化策略从混合改为被试内，基线准确率就提升了15.54个百分点。这表明被试间的均值和尺度差异是造成域偏移的重要原因之一。

2. **归一化与域适应可叠加**：被试内归一化+MMD达到76.25%，相比混合归一化基线（55.20%）提升+21.05%，远超单独使用任何一种方法的效果。

3. **标准差显著降低**：基线模型的标准差从±14.33%降至±8.86%，说明被试内归一化不仅提高了平均准确率，也增强了模型对不同被试的稳定性。

4. **方法排序变化**：混合归一化下DANN最优（69.56%），被试内归一化下MMD最优（76.25%），说明不同归一化策略下各方法的相对优势可能不同。

表3和图3展示了在固定被试内归一化条件下，三种域适应方法在不同λ值下的表现。

**表3：λ敏感性分析（被试内归一化，%准确率±标准差）**

| λ | CORAL | MMD | DANN |

![λ敏感性曲线](figures/lambda_sensitivity.png)

**图3：域适应损失权重λ对三种方法的影响**

**分析**：

1. **CORAL最稳定**：λ从0.1到5.0，准确率仅波动73.44%–74.51%，极差仅1.07%。这是因为CORAL仅对齐二阶统计量（协方差矩阵），对λ的变化不敏感。

4. **高λ下方法差距缩小**：λ=5.0时，CORAL（74.51%）、MMD（76.73%）和DANN（76.17%）的差距仅为2.26%。实际应用中，若不希望调参，选择CORAL（λ=1.0即可达73.44%）；若追求最高性能，选择MMD（λ=2.0–5.0可达76.5%以上）。

## 5 讨论

### 5.1 为什么被试内归一化如此有效？

混合归一化使用全局统计量进行z-score，但不同被试的EEG信号在均值和方差上存在量级差异。当目标域被试的分布参数与全局统计量偏差较大时，归一化后的特征仍处于训练分布之外。被试内归一化通过使每个被试的分布均近似标准正态，消除了这一量级差异，使得特征提取器只需对齐分布的高阶统计量（如协方差结构），大大降低了域适应的难度。

### 5.2 为什么MMD优于CORAL和DANN？

- **MMD vs CORAL**：CORAL仅对齐二阶统计量（协方差矩阵），而MMD通过多核RBF在高维空间中度量分布差异，能同时捕获均值偏移和协方差差异。在EEG数据中，被试间的差异不仅体现在方差上，也体现在均值上（即使被试内归一化后仍有残余偏移），因此MMD的对齐能力更强。

- **MMD vs DANN**：DANN的计算图更复杂（需要训练域分类器），在少量epoch（20个）和有限数据量下可能训练不充分。此外，DANN的α调度策略（从0到1逐渐增加域适应权重）在20个epoch内可能尚未充分生效。MMD作为解析损失，训练更稳定。

### 5.3 DANN在高λ下追赶MMD的原因

当λ从0.1增大到5.0时，DANN的域分类器获得更强的优化动力，对抗训练更充分。在高λ下，特征提取器被迫产生更具域不变性的特征，从而接近MMD的性能。然而，高λ也可能导致分类损失和域适应损失之间的不平衡，增大训练不稳定的风险。

### 5.4 局限性

1. 本实验仅在SEED数据集上验证，未在其他EEG情绪数据集（如DEAP、DREAMER）上测试泛化性
2. MLP架构较简单，未引入时序建模或图结构，可能限制了模型的表达能力
3. 被试内归一化在推理时需要目标域数据来计算统计量，在真正的新被试场景下需要在线更新或使用增量统计量
4. 仅验证了三种经典的域适应方法，未涉及更近期的方法如ADDA、MCD等

## 6 结论

本文在SEED数据集上系统研究了归一化策略和域适应方法对跨被试脑电情绪识别的影响。主要结论如下：

1. **被试内归一化是跨被试迁移的关键前置步骤**：仅通过改变归一化策略，基线LOSO准确率从55.20%提升至70.73%（+15.54%），标准差从±14.33%降至±8.86%。

2. **域适应方法可与归一化策略有效叠加**：被试内归一化+MMD达到最优76.25%（λ=1.0）/ 76.73%（λ=5.0），相比混合归一化基线提升+21.05%/+21.53%。

3. **MMD是最优的域适应方法**：在λ=1.0的默认设置下，MMD（76.25%）优于CORAL（73.44%）和DANN（74.89%），且在高λ下仍保持领先。

4. **CORAL是最鲁棒的方法**：对λ的敏感性极低（极差仅1.07%），适合不希望调参的实际部署场景。

5. **t-SNE可视化和混淆矩阵分析**从特征空间和分类结果两个角度验证了域适应方法的有效性，证实被试内归一化+MMD的组合能最大程度对齐源域与目标域的特征分布。
